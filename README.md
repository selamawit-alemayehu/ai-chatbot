# HiruyRecipe AI – Intelligent Recipe Assistant

## Project Overview

HiruyRecipe AI is an intelligent recipe assistant developed as part of the Hiruy Recipe Platform. It helps users explore recipes, ask cooking-related questions, and receive AI-powered assistance through a conversational interface.

The project extends a JavaScript AI chat application into a recipe-focused assistant designed to make discovering and preparing meals easier.

## Key Features

- **AI-Powered Conversations:** Interact with an AI assistant and receive intelligent responses.
- **Recipe Assistance:** Ask questions about recipes, ingredients, and cooking methods.
- **Amharic and English Support:** Communicate with the assistant in both languages.
- **Interactive Chat Interface:** Send messages and continue conversations naturally.
- **Gemini API Integration:** Connect the application to Google's Gemini AI service.
- **Hiruy Recipe Integration:** Designed to complement the Hiruy Recipe Platform.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Gemini API

## How It Works

1. The user enters a cooking-related question or request.
2. JavaScript processes the user's input.
3. The application sends the request to the Gemini API.
4. The AI generates a response.
5. The response is displayed in the chat interface.

## Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- A valid Gemini API key

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Configure your Gemini API credentials securely.

4. Open `index.html` in your browser or run the project using a local development server.

## Project Purpose

This project demonstrates the practical application of JavaScript, API integration, and AI-powered conversational interfaces in developing a domain-specific assistant for a recipe platform.
